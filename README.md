# JavaFX Slot Machine 🎰

**Programming II - Final Project**
**Developers:** İlker Batu İlk & Serdar Onaran

## Project Description
This project is a fully functional desktop Slot Machine game built with Java and JavaFX. It features a custom-built GUI (without FXML) and a local file-based persistency system. Users can register accounts, log in securely, and spin the reels using virtual credits. 

## Requirements
To run this project, you will need:
* **Java (JDK):** Version 21 or higher
* **Apache Maven**
